# VOLTKIT

A drum machine for the MPC Live III (standalone, modded unit), built from the
sound engine of the LXR V2 firmware by Erica Synths, which is open source
under the GPL. It has seven voices played from the MPC's pads: three drum
voices, a snare, a cymbal, and closed and open hi-hats. Each voice has the
LXR's own synthesis: oscillators with FM or mix modulation, envelopes, a
transient ("click") generator, filters, an LFO and velocity modulation, with
the LXR's FX bus (drive, ring modulator, compressor, delay) after them.

VOLTKIT runs the firmware's own DSP code, so it makes the same sound as the
firmware. It is an Open MPC VST2 plug-in with a native touchscreen skin, like
SACKFLEX, TINBOX and PerkyBits' MPC port.

> VOLTKIT is not made, supported or endorsed by Erica Synths. "Erica Synths"
> and "LXR" are their trademarks; they appear here only to say where the
> sound engine comes from.

## Pages

Each voice has a tab (**DRUM 1**, **DRUM 2**, **DRUM 3**, **SNARE**,
**CYMBAL**, **HATS**) with the LXR's sub-pages as keys along the top:

| Page | What's on it |
|---|---|
| OSC | coarse and fine pitch, waveform, pulse width (the snare adds its noise frequency and mix) |
| AMP | attack, decay (closed and open for the hats), slope, repeat (snare and cymbal) |
| MOD | pitch envelope (decay, slope, amount) and velocity modulation (destination, amount, velocity to volume) |
| FM / METAL | the drums' FM or mix oscillator; the cymbal's and hats' two modulator oscillators |
| CLICK | transient sample, level and pitch |
| FILTER | cutoff, resonance, type (low/high/band pass, notch, peak...), drive |
| LFO | rate or tempo sync, amount, wave, retrigger, phase, and its target: any parameter of any voice |
| MIX | volume, pan, sample rate reduction, drive, and output (main or the FX bus) |

**FX**: the FX bus (send voices to it with their MIX page's OUTPUT), its mix,
master volume and the global sample rate. Each effect keeps its own settings
when you switch between them.

**SETUP**: PAD LEARN, CLEAR PADS and INIT KIT.

Pads play General MIDI drum notes (DRUM 1 36, DRUM 2 45, DRUM 3 48, SNARE 38,
CYMBAL 49, CLOSED HAT 42, OPEN HAT 46, with a few neighbours each). Or tap
**PAD LEARN** and hit the pads you want for the seven voices in that order; it
finishes after the seventh, saves the map with the project, and new VOLTKIT
tracks start with it (`data/padmap.txt`). **STOP twice** stops all sound.
Everything is saved with the MPC project.

## How it's built

- `firmware/`: the LXR V2 firmware's sound engine, from
  [erica-synths/lxr-desktop-app](https://github.com/erica-synths/lxr-desktop-app)
  (commit in `firmware/UPSTREAM_COMMIT`), under its own licence and notice
  (`firmware/LICENSE`, `firmware/NOTICE.md`). The first commit of this
  repository is the unmodified import.
- `engine/`: what lets that code run outside the LXR: stand-ins for the STM32
  headers and Cortex-M instructions, the rest of the firmware reduced to stubs
  (the MPC does the sequencing), and a small C interface (`volt_engine.h`).
  The firmware keeps its state in global variables, so every plug-in instance
  loads its own copy of the engine library.
- `mpc/`: the MPC adapter, the controls (all generated by `gen_controls.py`
  from one table and the firmware's own parameter list, menu ranges and
  modulation targets) and the skin.

### Changes to the firmware

Each is marked `VOLTKIT` in the source and compiled only for VOLTKIT:

- no tightly coupled memory sections;
- the oscillator's phase-overflow test written in C instead of reading the
  Cortex-M status register;
- float-to-unsigned conversions saturate, as the Cortex-M7 does them (the
  engine is also built with `-fno-strict-float-cast-overflow -fwrapv`);
- the interpolating oscillators wrap within their 1024-entry tables instead of
  reading the next table (or past the last one);
- CC 0 no longer writes 64 KB past `midiParser_originalCcValues`;
- the FX distortion's diode table index stays inside the table;
- the ping-pong delay keeps its positions in its half of the buffer.

Values are also clamped to the ranges the LXR's menu allows before they reach
the engine, and the NRPN and bank-change slots of the parameter list are
ignored. These came out of running the engine under AddressSanitizer and
UBSan with random kits (`test/Fuzz.c`).

## Build and install

```bash
bash mpc/build.sh      # needs zig, cmake, ninja, python3; no Docker
bash mpc/deploy.sh root@mpc-live-iii.local 2222
```

Installing restarts the MPC app, so save your project first.

## Tests

```bash
cmake -S mpc -B build-host -G Ninja -DMPC_VST_DIR=<mpc-vst-plugins checkout>
cmake --build build-host
build-host/voltkit-mpc-test     # the adapter, through the wrapper's interface
build-host/voltkit-fuzz         # random kits; build with -fsanitize=address,undefined
```

`mpc/build.sh` also cross-builds both for the MPC (`mpc/build/aarch64/`).
